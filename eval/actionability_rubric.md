# Remediation Actionability Rubric (1–5 Scale)

This rubric defines the scoring criteria used for human peer assessment of the remediation steps generated by TraceMind.

| Score | Rating | Definition | Example / Indicators |
|---|---|---|---|
| **1** | **Harmful / Hallucinatory** | Suggests dangerous or completely nonsensical actions (e.g., dropping production tables, running unverified scripts, irrelevant cloud provider commands). | Suggests `rm -rf /` or references non-existent infrastructure components. |
| **2** | **Generic / Boilerplate** | Tautological or low-utility advice that offers no specific diagnostic or remedial direction. | *"Restart the server and monitor the logs to see if the issue persists."* |
| **3** | **Directionally Correct** | Identifies the correct subsystem or category of failure, but lacks concrete configuration parameters or step-by-step diagnostic commands. | *"Increase the database pool size and check active connections."* |
| **4** | **Specific & Actionable** | Provides targeted diagnostic commands, specific configuration flags, and a clear sequence of recovery steps. | *"1. Run `SHOW PROCESSLIST` to find stuck queries. 2. Increase `max_connections` from 50 to 150 in `my.cnf`. 3. Gracefully reload service."* |
| **5** | **Production-Ready & Mitigative** | Combines immediate mitigation, root cause rollback/fix, and long-term prevention (e.g. alerting rules, circuit breakers). | *"Immediate: Drain traffic via ALB target group. Rollback: Revert deployment to v2.1. Fix: Patch connection leak in `pool.py`. Long-term: Set Prometheus alert at 80% pool saturation."* |

---

### Evaluation Protocol
1. **Blind Evaluation:** Evaluators review the raw log excerpt alongside the generated remediation steps without knowing whether the output originated from RAG (TraceMind) or the Zero-Shot baseline.
2. **Sample Size:** 30 randomly selected held-out incidents from `data/test.json` evaluated across 2 independent annotators.
3. **Metric Reported:** Mean Actionability Score and Inter-Annotator Agreement (Cohen's Kappa).
